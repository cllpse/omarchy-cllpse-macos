# lazygit

lazygit's four gocui theme keys, in ANSI names so they follow the terminal.

The script is [`lazygit.sh`](lazygit.sh). It is runnable on its own and is also
called by [`../apply.sh`](../apply.sh), which owns the order. Numbered
sections below match the `# See README.md (n)` pointers in that script.
